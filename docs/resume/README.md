# Resume domain documentation

The resume/CV processing package is currently a scaffold. Parsing, structured
field extraction, normalization, persistence, and review flows have not yet
been implemented.

The planned package boundaries and implementation constraints are documented
in the [resume package README](../../src/resume/README.md). Resume-specific
database tables and retention rules should be documented here when those
requirements are defined. Reusable cross-domain schema decisions belong in
[the database schema overview](../database/database-schema-overview.md).
